Google Drive

Google Drive needs a one-time setup before it can be connected.

Add these to the .env file and restart docs0:

  • DOCS0_SETTING — the client ID of a Google OAuth client — that client's secret — 32 random bytes in base64; make one with openssl rand -base64 32

Create the OAuth client in Google Cloud Console (type Web application) and register this redirect URI on it:

http://localhost:8080/admin/sources/google/callback

The README has the steps.
