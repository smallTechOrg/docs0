Setup

Add DOCS0_ENCRYPTION_KEY to the .env file and restart docs0. It is 32 random bytes in base64; make one with openssl rand -base64 32. docs0 encrypts the key you paste with it.

Linear is not connected.

docs0 reads issues, projects and documents, and can file a new issue when someone asks (after they confirm). It never edits or deletes anything in Linear.

  1. In Linear open Settings → Account → Security & access.
  2. Under Personal API keys create a key and copy it (it starts with lin_api_).
  3. Paste it below. docs0 tests it, then stores it encrypted.

docs0 reads boards and cards, and can add a new card when someone asks (after they confirm). It never edits or deletes anything in Trello.

  1. Open trello.com/power-ups/admin and choose New to make a Power-Up. Open its API key page and copy the key.
  2. On that page choose to generate a Token, allow it, and copy it. It needs read and write access, because docs0 adds cards when asked.
  3. Paste both below. docs0 tests them, then stores them encrypted.
